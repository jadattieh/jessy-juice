⚙️ How to run this Django server on your local machine:

To launch this fully loaded Django server locally, follow these 3 simple command steps in your terminal:

  1. # 1. Install Django and required components (Optional)
    pip install django django-cors-headers
  2. # 2. Enter the backend folder and apply database migrations
    cd backend && python manage.py migrate
  3. # 3. Boot up the local web server
    python manage.py runserver

By default, your local Django server will spin up on http://127.0.0.1:8000/. The frontend Linker Panel will immediately pick up and sync the menu items, reviews, and post orders!
